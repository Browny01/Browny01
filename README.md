# Lucas Brown

I build practical software, tools, and small products across web, macOS, automation, AI, and real-time data.

Most of my work focuses on turning useful ideas into clean, usable products rather than building around a specific stack.

## Public Projects

### [DisplaySwitcher](https://github.com/Browny01/DisplaySwitcher)
A lightweight native macOS menu-bar app for saving multi-monitor layouts as presets and switching between them instantly. Includes global shortcuts, Shortcuts.app actions, a CLI, reconnect handling, and Homebrew installation.

**Swift · SwiftUI · macOS · CLI**

### [Base](https://github.com/Browny01/base)
A personal command centre for managing tasks, projects, notes, focus, finance, news, and day-to-day work. Built across the web, iPhone, and Mac with offline support and AI-assisted features.

**Next.js · React · TypeScript · SwiftUI · Vercel**

### [SportPulseCLI](https://github.com/Browny01/SportPulseCLI)
A terminal-based live sports dashboard for NBA, NHL, AFL, and NFL scores, player statistics, standings, timelines, and more. It also includes a native macOS menu-bar companion.

**Python · SwiftUI · Sports Data**

### [Ultimate Naughts and Crosses](https://github.com/Browny01/ultimate-naughts-and-crosses)
A browser-based version of Ultimate Naughts and Crosses built as a small game project.

**JavaScript · Web**
